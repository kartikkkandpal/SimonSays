# Simon Says Game 🎮

A memory-based Simon Says game built using HTML, CSS, and JavaScript. Players must repeat an ever-growing sequence of colors. The game features a responsive UI, light/dark mode toggle, sound effects, and a high score tracker using local storage.

## Features

✅ **Memory Sequence Game:** Reproduce increasingly complex sequences of colors.  
🌗 **Dark/Light Mode Toggle:** Customize your UI with a theme switch.  
🔉 **Sound Effects:** Feedback sounds for button clicks and wrong answers.  
🏆 **High Score Tracker:** Stores your highest level using localStorage.  
📱 **Responsive Design:** Works well across desktops and mobile devices.  
🚫 **Game Over Logic:** Immediate feedback and reset option when wrong color is chosen.
